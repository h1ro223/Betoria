ルール

見たいゲームを選んでください。アカウント・メダル・フレンドはすべてのゲームで共通です。

マーブルレースの基本

  • 8つのボールが走るレースで、どれが上位に入るかを当てるゲームです。競馬と同じ仕組みだと思ってください。
  • 会場は常時開催です。部屋を作る必要はなく、入ればすぐ次のレースに参加できます。1人でも遊べます。
  • 1レースはおよそ70秒です。投票30秒 → 秒読み3秒 → レース28秒 → 払い戻し10秒で、そのまま次のレースが始まります。
  • 出走する8つのボールは固定ですが、強さは毎レース変わります。オッズもそれに合わせて毎回変化します。
  • 投票しなかったレースは、ただ見ているだけでもかまいません。
  • 会場ではチャットが使えます。「いけーっ！」などの応援スタンプを押すだけでも参加できます。

買い目(3種類)

  • 単勝 … 1着になるボールを1つ選びます。当てるのは難しいぶん配当が高くなります。
  • 複勝 … 選んだボールが3着以内に入れば的中です。当たりやすいぶん配当は低めです。
  • 馬連 … 1着と2着になる2つの組み合わせを当てます。順番は問いません(1-2でも2-1でも同じ)。

オッズと払い戻し

  • オッズはボールの強さから自動で計算されます。強いボールほど低配当、弱いボールほど高配当です。
  • 払い戻しは 投票額 × オッズ です(端数は切り捨て)。オッズには投票額そのものが含まれます。
  • オッズは投票した瞬間の値で固定されます。あとから変動することはありません。
  • 投票は10メダルから、1回あたり100,000メダルまで。
  • 投票できるのは1レースにつき1点だけです。買ったあとは締め切りまで変更できないので、よく考えて選んでください。
  • レースが始まると会場から出られません。払い戻しを受け取るまでお待ちください。

レベルと経験値

  • 投票したレースが終わるごとに +15 EXP。
  • 1つでも的中していれば、さらに +25 EXP。

ランキング

  • マーブルレースのランキングはほかのゲームとは別に集計されます。
  • 1レースの払い戻し合計から投票額を引いた分が記録されます。

ハイ&ローの基本

  • 場に置かれたカードより、次のカードが高いか低いかを当てるゲームです。
  • 強さは A(いちばん弱い)→ 2 → 3 → … → Q → K(いちばん強い) の順です。マークの違いは関係ありません。
  • ベットは1回100メダル固定です。最初の予想を出すことが、そのままベットになります。
  • 同じ数字が出た場合(ドロー)は負け扱いで、ベットは没収されます。
  • カードは1組52枚を上から順に使います。使い切ると新しくシャッフルし直します(山札の残り枚数は画面上部に出ます)。

配当(グリード方式)

  • 当てるたびに倍率が 1.5倍ずつ 積み上がります。
  • 1回的中 150 / 2回 225 / 3回 337 / 4回 506 / 5回 759 メダル(100メダルベット時)。
  • 当てたあとは 「もう一度予想する」か「回収する」 を選べます。回収するとその時点の枚数が確定します。
  • 1回でも外すと、積み上げた分はすべて没収です。引き際が勝負です。
  • 5回連続で的中すると上限となり、自動的に回収(MAX WIN)になります。

オンライン

  • 全員が同時に予想を出し、当てた人だけが次に進みます。他の人の予想は画面に表示されます。
  • 持ち時間は15秒です。時間切れになると、まだ参加していない人は見送り、勝ち残っている人は自動で回収されます。
  • 全員の勝負がついたら、自動で次のラウンドが始まります。休みたいラウンドは何も押さなければ大丈夫です。
  • 人のプレイヤーが2人以上必要です。3人以上の部屋ではCPUの自動補充も使えます。

シングルプレイ(練習モード)

  • 開始のたびに専用メダル1000枚が配られます。アカウントの所持メダルは増減しません。
  • 経験値・戦績・ランキングにも記録されません。ルールを覚えるための練習用です。
  • メダルが100枚を下回るとゲーム終了です。

レベルと経験値

  • オンラインで1ラウンド遊ぶごとに +10 EXP。
  • さらに的中1回につき +12 EXP(5連続的中なら合計70EXP)。
  • 外しても参加分のEXPは受け取れます。

ランキング

  • ハイ&ローのランキングはブラックジャックとは別に集計されます。
  • 対象はオンラインのみです。練習モードは含みません。

基本

  • 手札の合計を 21 に近づけます。21を超えると即負け(バースト)。
  • 2〜10は数字通り、J・Q・Kは10、Aは1または11の有利な方。
  • HITでカードを1枚追加、STANDで手札を確定。
  • ディーラーは合計17以上になるまで引き続けます。
  • プレイヤー同士は戦いません。全員がディーラーと勝負します。

配当

  • BLACKJACK(最初の2枚で21)… ベットの2.5倍。ボタンを押して自分で宣言します。
  • 勝ち … ベットの2倍
  • 引き分け(プッシュ)… ベットが返却
  • 負け・バースト … ベット没収
  • SURRENDER … 最初の2枚の時だけ選択可。勝負を降りて、ベットの半分だけ没収されます。
  • DOUBLE(ダブルダウン)… 最初の2枚の時だけ選択可。ベットを倍にして1枚だけ引き、そのままSTANDになります。メダルが足りないときは選べません。

連勝

  • WIN・BLACKJACKが続くと、画面上部に「🔥 X連勝中!」が表示されます(2連勝から)。
  • 引き分け(PUSH)では連勝は途切れません。負け・バースト・SURRENDERでリセットされます。

レベルと経験値

  • 1ラウンド遊ぶごとに +10 EXP。
  • 結果に応じて追加 … BLACKJACK +40 / 勝ち +25 / 引き分け +12 / 負け +5 / SURRENDER +6。
  • 次のレベルに必要なEXPは 100 + (現在Lv−1)×50。

オンライン

  • ホストが部屋を作成し、発行された4桁のルームIDを共有します。
  • 全員が揃ったらホストがゲーム開始を押すと、3・2・1のカウントダウン後に開始します。
  • 各自ベットを決め、全員が揃ったらホストがカードを配ります。
  • 手番は30秒。時間切れは自動でSTANDになります。
  • エンジョイモードでは「CPUを自動補充」で人数の空きをCPUが埋められます(3人以上の部屋のみ)。
  • どのモードでも、人のプレイヤーが2人以上揃わないとゲームを開始できません。

チャンピオンモード

  • プレイヤー全員に大会専用メダル1000枚が配られます(アカウントのメダルとは別で、CPUは参加しません)。
  • 10・30・50ラウンド、または自由入力(10〜100)から回数を選び、指定ラウンドが終わるか、自分以外が全員脱落するまで対戦します。
  • CPUは参加しないため、人のプレイヤーが2人以上必要です。
  • メダルが0になると脱落し、以降は観戦のみになります(途中退出も可能ですが、その回のEXPは受け取れません)。
  • EXPは実際に勝負したラウンド数で決まります。SURRENDERしたラウンドは対象外です。
  • 生存して終了なら勝負したラウンド分の100%+順位ボーナス、脱落した場合は50%(いずれもエンジョイモードの1.25倍を基準に、参加人数が多いほど増加)。
  • 順位ボーナスは「勝負したラウンド数 ÷ 規定ラウンド数」で按分されるため、降り続けても稼げません。
  • 全額ベットボーナス … 持っている大会メダルを全額ベットして勝つと、獲得メダルがさらに1.5倍になります(例: 300枚でBLACKJACK → 300×2.5=750 → ×1.5=1125枚 / WIN → 300×2=600 → ×1.5=900枚)。ダブルダウンで手持ちを使い切った場合も対象です。

はじめての方へ

  • タイトル画面の 🎓 チュートリアル では、実際のゲーム画面を使って遊び方を学べます。
  • 全6章で、4つの選択肢(HIT / STAND / DOUBLE / SURRENDER)と、5つの結果(WIN / LOSE / BUST / PUSH / BLACKJACK)をひと通り体験できます。
  • 「次へ」を押すだけで進みます。メダルや戦績には影響しないので、気軽に試してください。

シングルプレイ(練習モード)

  • ゲーム開始のたびに専用メダル1000枚が配られます。アカウントの所持メダルは増減しません。
  • 経験値とエンジョイモードの戦績は今まで通り記録されます。
  • ノルマモードをオンにすると、目標メダルに到達でゲームクリア、0枚でゲームオーバーです。
  • シングルプレイでは広告によるメダル獲得はできません。

早抜けモード

  • 全員に大会専用メダル1000枚が配られ、決められた枚数を超えるまでの早さを競います(アカウントのメダルは減りません)。
  • 条件は10000メダル超え(おすすめ)か、ホストが決めた枚数のどちらかです。
  • 条件を超えると勝ち抜けとなり、そのまま観戦に移ります。残り1人になった時点でゲーム終了で、その人はリタイア扱い(順位は「ー」)になります。
  • 同じラウンドで複数人が同時に達成した場合、そのラウンドのベット額が多い人が上位になります。
  • 大会メダルが0枚になった場合もリタイアです。
  • EXPは抜けた順位で決まります(1抜け120 / 2抜け80 / 3抜け50、リタイアは一律20)。ラウンド数や目標枚数では変わりません。
  • 誰も勝ち抜けられなかった場合は、全員0EXPです。

ランキング

  • 総獲得枚数 … その日にラウンドで勝って得たメダルの合計です。
  • 一撃獲得枚数 … その日の中で、1ラウンドの勝利で得た最も多い枚数です。
  • 対象はオンラインのエンジョイモードです。ログインボーナス・広告・練習モード・大会メダルは含みません。
  • ランキングはゲームごとに別々に集計されます(ブラックジャックとハイ&ローは混ざりません)。
  • 集計は0:00〜23:59まで。結果は翌日の23:59まで「前日」で確認できます。一撃のみ歴代の記録も残ります。
  • 同じ枚数の場合は同率順位になります(1位・1位・3位のように表示)。
  • 前日のランキングに入賞していると、翌日🔔通知でお知らせが届きます。

ログインボーナス

  • その日はじめてアクセスすると500メダルを受け取れます(0:00で切り替わります)。
  • さらに広告を最後まで見ると500メダル、合計1000メダルになります。
  • 受け取っていないボーナスがあると、タイトル画面に🎁ボタンが表示されます。

フレンド・招待

  • 画面右上の❤ボタンからフレンド一覧と、届いているフレンド申請を確認できます。
  • 待機ルームで他のプレイヤーの右にある「申請」を押すとフレンド申請を送れます。フレンドになると名前の右に🤝が付きます。
  • 待機ルームの「招待する」から、オンライン中のフレンドを招待したり、招待URLを発行して共有できます。
  • 招待URLを開くとその部屋に直接参加できます(未ログインの場合は、ログイン・新規登録のあとに参加します)。

観戦

  • 部屋一覧で「試合中」になっている部屋は、「観戦」ボタンから途中参加できます。観戦の人数制限はありません。
  • 観戦者は盤面を見るだけで、操作やチャットの閲覧はできません。いつでも観戦をやめられます。
  • ゲーム画面の上部に👁と観戦人数が表示されます。
  • 満員の部屋は赤字の「満員」と表示され、参加できません(試合が始まれば観戦できます)。
