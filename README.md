# BLACKJACK 4 (v2.1)

最大4人で遊べるブラックジャック。シングルプレイ(CPU対戦)とオンラインのルーム対戦(エンジョイ/チャンピオン)に対応しています。

made by hiro / ヒロ — https://github.com/h1ro223

## ファイル構成

```
blackjack4/
├ index.html        画面全体(タイトル/ロビー/待機ルーム/カウントダウン/チャンピオン結果/ゲーム)
├ style.css         スタイル
├ script.js         クライアント処理
├ server.js         Renderで動かすサーバー(Express + Socket.io + PostgreSQL)
├ package.json      依存パッケージ
├ BGM.mp3           ★自分で用意(BGM / ループ素材)
└ ad/               ★自分で用意(疑似広告の動画)
   ├ ad1.mp4
   ├ ad2.mp4
   └ ad3.mp4
```

★のファイルは無くてもゲームは動きます(BGMは鳴らず、広告はダミー画面になります)。

BGMはWebAudioで再生しているため、読み込み時にメモリ上で非圧縮に展開されます。
**1〜3分程度のループ素材**を推奨します(長すぎるとスマホでメモリを圧迫します)。
自動でループ再生されるので、繋ぎ目が自然な素材だときれいに鳴ります。

## Renderへのデプロイ手順

### 1. PostgreSQL を作る

1. Render のダッシュボードで **New → PostgreSQL** を選択
2. 名前を決めて、リージョンは `Singapore` あたりを選択(日本から近い)
3. Free プランで作成
4. 作成後、**Internal Database URL** をコピーしておく

> 無料の PostgreSQL は作成から一定期間で削除されます。期限が来たら作り直して `DATABASE_URL` を差し替えてください。
> v1.0から引き続き使う場合、チャンピオン戦績用のカラムは起動時に自動でマイグレーション(`ALTER TABLE ... ADD COLUMN IF NOT EXISTS`)されるので、作り直す必要はありません。

### 2. Web Service を作る

1. **New → Web Service** を選び、このリポジトリを連携
2. 設定は以下の通り

   | 項目 | 値 |
   |---|---|
   | Runtime | Node |
   | Build Command | `npm install` |
   | Start Command | `npm start` |
   | Instance Type | Free |

3. **Environment** に環境変数を追加

   | Key | Value |
   |---|---|
   | `DATABASE_URL` | 手順1でコピーしたInternal Database URL |
   | `AUTH_SECRET` | 適当な長いランダム文字列(ログイン状態の署名に使用) |

4. Deploy を実行

`AUTH_SECRET` を設定しないと、再起動のたびに全員ログアウトされます。必ず設定してください。

### 3. 動作確認

デプロイ後のURLにアクセスしてタイトル画面が出ればOKです。
`https://あなたのアプリ.onrender.com/api/health` を開くと接続状態が確認できます。

```json
{"ok":true,"db":"postgres","rooms":0,"version":"2.0.0"}
```

`"db":"memory"` と出た場合は `DATABASE_URL` が読めていません。

## GitHub Pages でシングルプレイだけ公開する場合

`index.html` / `style.css` / `script.js` と素材だけを置けば、シングルプレイはそのまま遊べます。

オンラインプレイも使いたい場合は `script.js` の先頭にある定数に Render のURLを入れてください。

```js
const ONLINE_SERVER = 'https://あなたのアプリ.onrender.com';
```

空のままなら、同じサーバーから配信されている前提で動きます(Renderに全部置く場合はこのままでOK)。

---

## 無料プランの注意点

Render の Free プランは **15分アクセスが無いとスリープ**します。復帰に30秒〜1分ほどかかるため、対戦前に一度URLを開いて起こしておくとスムーズです。

また、スリープするとサーバー上のルーム情報は消えます(アカウント・メダル・戦績はPostgreSQLに残ります)。チャンピオンモードの進行中にサーバーが再起動された場合も、そのルームの進行状況は失われます。

## 仕様メモ

### アカウント
- ユーザー名・パスワードともに **英数字1〜8文字**
- パスワードは scrypt でハッシュ化して保存
- 初期メダル 1000枚
- アカウント画面から**削除**が可能(パスワード確認必須、取り消し不可)

### レベル・経験値(エンジョイモード)
- 1ラウンドごとに **+10 EXP**
- 結果に応じて追加 … ブラックジャック **+40** / 勝ち **+25** / 引き分け **+12** / 負け **+5** / サレンダー **+6**
- 次のレベルに必要なEXP = `100 + (現在Lv − 1) × 50`
- 最大 Lv.99

### チャンピオンモード
- 参加者全員に**大会専用メダル1000枚**を配布(アカウントの所持メダルとは別枠、対戦終了後も引き継がれません)
- ラウンド数は **10 / 30 / 50 / 自由入力(1〜200)** から選択
- 指定ラウンドの終了、または自分以外が全員脱落した時点で終了
- メダルが0になると**脱落**し、以降は観戦のみ(退出も可能、その場合はEXP無し)
- EXP計算(サーバー: `server.js` の `championRoundExp` / `maybeEndChampionship` 参照)
  - 1ラウンドあたりの基礎EXP = `10 × 1.25 ×(参加人数に応じた係数)`
  - 係数は2人=1.2 / 3人=1.4 / 4人=1.6(人数が多いほど高難度とみなして増加)
  - **脱落した場合**: 脱落までの経過ラウンド数 × 基礎EXP × **50%**
  - **生存して終了した場合**: 経過ラウンド数 × 基礎EXP × **100%** + 順位ボーナス(1位+80 / 2位+40 / 3位+20 / 4位+8、いずれも人数係数を掛けたもの)
  - 自分以外が全員脱落して早期終了した場合も、その時点までのラウンド数を基準に上記の計算式が使われます
  - 同メダルで並んだ場合は同順位(引き分け)として扱われます
- CPUはチャンピオンモードには参加しません(プレイヤーのみ)

### オンライン
- ルームIDは4桁(紛らわしい `0 O 1 I` は除外)
- ホストが「ゲーム開始」を押すと**3・2・1のカウントダウン**後に開始
- 全員のベットが揃うと、**ホストだけ**が「カードを配る」を押せる
- 手番は30秒でタイムアウト → 自動スタンド
- ホストが抜けた場合は次のプレイヤーが自動でホストになる
- エンジョイモードのみ「CPUを自動補充」で人数の空きをCPUが埋められます(チャンピオンモードでは無効)

### ゲームルール
- 6デッキ、残り25%を切ると自動シャッフル
- ディーラーは17以上でスタンド
- ブラックジャックは配当2.5倍、勝ちは2倍、引き分けはベット返却
- **サレンダー**は最初の2枚の時だけ選択可、ベットの半分が返却されます

### サウンド
- BGM・効果音ともに **WebAudio** で再生
- HTMLの `<audio>` を使っていないため、iPhoneでも音量スライダーが効き、Dynamic Island / ロック画面の再生コントロールにも表示されません
- 広告の再生中はBGMが自動で絞られます

### チャット(オンライン専用)
- 待機ルーム・ゲーム中どちらでも使用可能
- テキストは**60文字**まで、定型スタンプは 👍 🎉 😂 😭 🔥 🙏 の6種
- 連投防止のため**350ms**の送信間隔制限あり(サーバー側)
- スタンプはサーバー側でホワイトリスト検証しています
- 入室・退出・ホスト交代はシステムメッセージとしてチャット欄に流れます
- パネルを閉じている間は未読バッジと画面右側のポップアップで通知します
- ログはサーバーに保存されず、部屋を出るとクリアされます

### 演出
- HIT / STAND / BUST / WIN / LOSE / PUSH / SURRENDER に画面中央のカットインを表示
- **ブラックジャック**は金のグラデーション文字+紙吹雪の特別演出(約2秒)
- `prefers-reduced-motion` が有効な環境ではアニメーションを抑制します

### 操作
- `H` … ヒット
- `S` … スタンド
- `Enter` … 配る / 次のラウンドへ
- `Esc` … モーダルを閉じる
